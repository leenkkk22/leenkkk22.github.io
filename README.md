# 이인호 포트폴리오

🌍 Java/Spring 기반 백엔드와 React를 활용한 풀스택 개발을 목표로 공부하는 **이인호**입니다.

사용자 경험과 코드 품질을 모두 고려하며, RESTful API 설계·데이터베이스 모델링·프론트엔드 연동까지 end-to-end로 프로젝트를 수행해 왔습니다.  
새로운 기술을 빠르게 학습하고, 팀과의 협업을 통해 더 나은 결과물을 만드는 것을 즐깁니다.
